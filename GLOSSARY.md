# Запись на звонок

Сервис бронирования времени: владелец календаря публикует типы встреч, гость занимает свободный слот и записывается на звонок.

## Language

**Владелец календаря**:
Единственный заранее заданный хозяин расписания. Заводит типы встреч и смотрит список предстоящих встреч.
_Avoid_: админ, хозяин, пользователь

**Гость**:
Посетитель без аккаунта, который выбирает тип встречи и записывается на свободный слот.
_Avoid_: пользователь, клиент, посетитель

**Тип встречи**:
Шаблон встречи, который заводит владелец: название, описание и длительность в минутах.
_Avoid_: событие (это про конкретную встречу), вид брони

**Слот**:
Конкретный интервал времени внутри окна записи, на который гость может записаться. Длится столько, сколько выбранный тип встречи.
_Avoid_: окошко, интервал (без уточнения)

**Бронирование**:
Занятый слот: гость занял конкретное время по конкретному типу встречи.
_Avoid_: заказ, бронь (в названиях сущностей), встреча (это то, что случится после)

**Окно записи**:
14 календарных дней, внутри которых гость может выбрать слот. Сдвигается с текущей датой.
_Avoid_: календарь (это UI-элемент), период

## Страницы

**Главная страница**:
Маршрут `/`. Рассказывает про сервис и ведёт на страницу записи.
_Avoid_: лендинг, хоум

**Страница записи**:
Маршрут `/booking`. Каталог типов встреч и календарь со свободными слотами для гостя.
_Avoid_: страница бронирования, страница календаря

**Страница владельца**:
Маршрут `/admin`. Список предстоящих встреч всех типов.
_Avoid_: админка, личный кабинет
